# Smart Room Energy & Occupancy Monitor

## Overview
An Arduino UNO based smart room monitoring system developed and simulated using Wokwi.

## Components
- Arduino UNO
- PIR Sensor
- LDR
- LED
- Other required components

## How It Works
The system uses sensors to monitor room occupancy and light conditions
and makes simple automatic decisions.

## Simulation
This project was designed and tested using Wokwi.

## Applications
- Smart rooms
- Energy saving
- Automatic lighting
- Room monitoring

## Technologies
- Arduino UNO
- Embedded C
- Wokwi
